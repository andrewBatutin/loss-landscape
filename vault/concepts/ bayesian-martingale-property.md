# Bayesian Martingale Property

## Intuition

For exchangeable data where order doesn't matter a Bayesian predictor must satisfy 

```
E[X{n+1} | x_1, x_2, x_3] = E[X{n+1} | x_2, x_1, x_3] 
```

## Essence

Same data different order - same prediction. 
Coin flip.
